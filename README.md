## Ишга тушириш

### 1. Supabase лойиҳаси (бепул)
1. https://supabase.com да рўйхатдан ўтинг ва **New project** яратинг (регион: Frankfurt ёки яқинроқ).
2. **SQL Editor** да `supabase/migrations` ичидаги файлларни тартиб билан ишга туширинг:
   `0001_schema.sql`, `0002_storage.sql`, `0003_seed_rooms.sql`.
3. **Authentication → Sign In / Providers → Email**: «Enable Email provider» ёқилган бўлсин.
4. **Authentication → Emails → Magic Link** шаблонига кодни қўшинг, шунда хатда 6 хонали код ҳам келади:
   ```html
   <h2>Тизимга кириш</h2>
   <p>Кириш коди: <b style="font-size:22px">{{ .Token }}</b></p>
   <p>Ёки шу ҳаволани босинг: <a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email">Кириш</a></p>
   ```
5. **Authentication → URL Configuration**: Site URL = сайт манзили (масалан `https://zal.vercel.app`), Redirect URLs га `https://zal.vercel.app/**` ва `http://localhost:3000/**` қўшинг.
6. Кўп хат юбориш учун **Authentication → SMTP** да ўз почта серверингизни улаш тавсия этилади. Supabase'нинг ўзи соатига бир неча хат юборади, холос.
7. **Project Settings → API** дан `Project URL` ва `anon public` калитни олинг.

### 2. Компьютерда
```bash
cp .env.example .env.local   # иккита калитни ёзинг
npm install
npm run dev                  # http://localhost:3000
```

### 3. Интернетга чиқариш (Vercel, бепул)
1. https://vercel.com га GitHub орқали киринг → **Add New Project** → `zaldan-foydalanish` репозиторийсини танланг.
2. Environment Variables: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_SITE_URL`.
3. **Deploy**. Сўнг Supabase'даги Site URL ни Vercel берган манзилга алмаштиринг.

## Синовлар
```bash
npm test          # сана, соат, телефон, форма текширувлари (Vitest)
npm run typecheck
```
Маълумотлар базаси қоидалари (тўқнашув, роллар, телефонни яшириш) `supabase/tests/booking_rules.sql` да. Улар оддий PostgreSQL 16 да ишга туширилади:
```bash
cd supabase/tests
psql -d test -v ON_ERROR_STOP=1 -f local_stub.sql -f ../migrations/0001_schema.sql -f ../migrations/0003_seed_rooms.sql -f booking_rules.sql
```

Ишлаб чиқиш режимида `/dev/preview` саҳифаси Supabase'сиз намунавий маълумотлар билан интерфейсни кўрсатади (production'да ўчиқ).
